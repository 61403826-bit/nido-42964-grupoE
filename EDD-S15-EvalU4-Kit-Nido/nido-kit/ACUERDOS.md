- Tiempo maximo para responder un mensaje del equipo: Respuesta inmediata (en tiempo real durante la sesión de trabajo).
- Las decisiones se registran en: El grupo de WhatsApp, Pull Requests en GitHub y en las actas de este archivo.
- Si no estamos de acuerdo, decidimos asi: Consenso rápido en el chat del grupo priorizando que el código compile sin errores y cumpla la rúbrica.
